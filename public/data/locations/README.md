# Nigeria locality index

This directory contains a local, split-by-state copy of the `full.json` dataset from [temikeezy/nigeria-geojson-data](https://github.com/temikeezy/nigeria-geojson-data), distributed under the included MIT license.

The source provides 37 states/FCT, 774 LGAs, and 8,809 named electoral wards/registration areas with representative latitude/longitude points. The game uses these points for navigation and procedural scene seeds. A ward is not a complete gazetteer of every village, street, or household; coordinates are not road networks or legal boundaries. `Nassarawa` is normalized to `Nasarawa` to match this project’s state directory.
